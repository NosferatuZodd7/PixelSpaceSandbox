## Astronomical data

The Solar System preset (`data/presets/solar_system.json`) cites a source for
every value. The build environment could not reach NASA's servers, so the
values were transcribed from these public sources and then checked against
real events by the tests (Mars, Jupiter and Saturn oppositions within 0.15°;
the lunar eclipse of 2025-09-07 and the solar eclipse of 2024-04-08).

| Data | Source |
| --- | --- |
| Planet and Pluto orbits (elements and drifts per century) | E. M. Standish, JPL Solar System Dynamics, *Approximate Positions of the Planets*, Table 1 (1800–2050): https://ssd.jpl.nasa.gov/planets/approx_pos.html |
| Masses, radii, rotation, axial tilt, albedo | NASA NSSDCA Planetary Fact Sheets: https://nssdc.gsfc.nasa.gov/planetary/factsheet/ |
| The Moon's position | The Astronomical Almanac, low-precision formulae for the Moon |
| Ceres orbit | JPL Small-Body Database (epoch JD 2460000.5), as listed by TheSkyLive: https://www.theskylive.com/ceres-info |
| Eris orbit | JPL osculating elements (2014 epoch), as listed by Johnston's Archive: https://johnstonsarchive.net/astro/astmoons/am-136199.html |
| Moons' sizes, periods, eccentricities, inclinations | JPL Solar System Dynamics, Planetary Satellite Mean Elements and Physical Parameters: https://ssd.jpl.nasa.gov/sats/ |
| Directions of the planets' poles | IAU WGCCRE 2015 report (Archinal et al. 2018) |
